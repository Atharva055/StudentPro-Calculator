# StudentPro Calculator 🧮

A modern desktop calculator made using Python and CustomTkinter.

Designed specially for students with normal, scientific, and commerce calculation tools in one simple application.

## ✨ Features

- 🖥️ Modern dark interface
- 📱 Responsive resizable design
- ⏰ Live date & time display
- 🧮 Basic calculations
- 🔬 Scientific functions
  - Square root
  - Trigonometry
  - Logarithm
  - Powers

- 📚 Commerce Calculator
  - GST Calculator
  - Profit Percentage
  - Loss Percentage
  - Simple Interest
  - Compound Interest
  - Discount Calculator

- 📝 Calculation history saving
- ⌨️ Keyboard shortcuts

## 🛠️ Built With

- Python
- CustomTkinter
- Math Module
- Datetime Module
